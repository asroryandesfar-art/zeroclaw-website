HOW IT WORKS

Three steps
for every order.

  1. 01

    Create a link or QR

    You run one command for an order. It returns a Solana Pay link with a unique reference, and can save it as a QR image.

    ↗
  2. 02

    Your customer pays

    The customer opens the link or scans the QR in their Solana wallet and pays in SOL or USDC. Funds go directly to your wallet.

    ↗
  3. 03

    Check the status

    You run the CLI again with the order reference. It reads the blockchain and reports whether the order is still pending or paid.

    ↗
DEVNET EXAMPLE
# Install the package and activate your license
$ npm install --offline --ignore-scripts --no-audit --no-fund \
    /path/to/asrori24-zeroclaw-solana-pay-0.1.0.tgz
$ ZSP=./node_modules/.bin/zeroclaw-solana-pay
$ $ZSP activate --key-file /path/to/your-license.key

# 1. Create a payment link for one order (1 USDC)
$ $ZSP run create-url --amount 1 --token USDC

#    Save it as a QR image
$ $ZSP run render-qr --url "$PAYMENT_URL" --out invoice.png

# 2. Your customer scans the QR and pays

# 3. Check the payment status
$ $ZSP run settle --reference "$REFERENCE"
{ "status": "pending", "newly_settled": false }
Set your public wallet and devnet settings first; the included guide lists every step.

FAQ

Good
to know.

Who is this for?+

Developers who want to accept SOL or USDC in their own app or store. It is a command-line tool, not a hosted checkout page.

Do you hold my money or my keys?+

No. Your customer pays from their own wallet straight to your wallet. The CLI only needs your public wallet address and reads the blockchain to check the payment.

Does it support Solana Mainnet?+

Supports Solana Mainnet. The payment workflow was tested on Solana Devnet. Devnet is the default; the included guide shows the settings that switch the CLI to Mainnet. Run a small test payment before you take live orders.

What do I need to run it?+

Linux x64 with glibc 2.34 or newer, Node.js 20 or newer, and npm. You also need a Solana RPC endpoint and your public wallet address.

Does the license expire?+

No. The version you receive keeps working. Updates are included for 12 months and technical support for 90 days.
